# Tema SoftForge Default React

Tema padrão integrado oficial do SoftForge, construído com:
- **Engine**: React 18 + TypeScript + Vite
- **Estilização**: Tailwind CSS + Design Tokens Universais (`--sf-*`)
- **Componentes**: Radix UI / Shadcn UI primitives

## Estrutura
- `softforge-theme.json`: Manifesto de tokens e metadados lidos pela API SoftForge (`/api/v1/system/themes/default-react`).
- Aplicação principal localizada em `apps/web/`.
