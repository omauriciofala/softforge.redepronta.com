Guia de Início Rápido (Quickstart)

SoftForge — Framework Fullstack AI-Native
100% construído com e para IA • Spec-Driven • Vertical Slice Architecture • Docker-First

1. Pré-requisitos

  • Python 3.12+ (com pip ou uv)
  • Node.js 20+ (com npm ou pnpm)
  • Docker e Docker Compose (opcional para SQLite, obrigatório para Postgres)

2. Inicialização em 3 Passos

Passo 1: Configurar Variáveis

cp .env.example .env

Passo 2: Iniciar o Backend

# Criar ambiente virtual
python -m venv apps/api/.venv

# Ativar e instalar (Windows):
.\apps\api\.venv\Scripts\python.exe -m pip install -e "apps/api[dev]"

# Executar API com recarga automática:
.\apps\api\.venv\Scripts\python.exe -m uvicorn src.main:app --reload

Passo 3: Criar uma Nova Fatia em 2 Minutos

python tools/scripts/slice_scaffold.py --name invoices

Esse comando gera schemas Pydantic v2, models SQLAlchemy 2.0 Async, service, router e testes com SQLite in-memory.

Manual do Framework

1. Por que Vertical Slice Architecture?

Em arquiteturas em camadas convencionais (controllers, services, repositories separados), o código de uma funcionalidade fica espalhado em várias pastas. Quando uma IA atua no projeto, ela precisa manter muitos arquivos na janela de contexto de tokens, gerando alucinações.

No SoftForge, cada fatia é 100% autossuficiente:

apps/api/src/slices/<feature>/
├── schemas.py       # Contratos OpenAPI & DTOs Pydantic v2
├── models.py        # Tabelas SQLAlchemy 2.0 Async
├── service.py       # Lógica pura de negócio
├── router.py        # Endpoints HTTP da fatia
└── tests/           # Testes de integração isolados com SQLite

2. Multi-Tenancy e RBAC

Hierarquia de papéis por Workspace:

  • Owner (Nível 4): Controle total da organização e faturamento.
  • Admin (Nível 3): Gestão de membros e configurações de projetos.
  • Member (Nível 2): Criação e edição de dados do domínio.
  • Viewer (Nível 1): Apenas visualização.

Fluxo de Desenvolvimento com IA

A Constituição do Agente (.ai/AGENTS.md):

O arquivo .ai/AGENTS.md na raiz do projeto instrui qualquer IA (Cursor, Antigravity, Claude Code) a nunca quebrar as regras de fatias verticais, nunca misturar modelos de banco com DTOs e sempre rodar o validador de guardrails.

O Ciclo em 6 Etapas:

  1. Scaffold: python tools/scripts/slice_scaffold.py --name <fatia>
  2. Contratos: Definir entrada e saída em schemas.py
  3. Lógica: Implementar service.py e rotas em router.py
  4. Testes: Cobrir com testes assíncronos em tests/
  5. Exportar: python tools/scripts/export_openapi.py
  6. Verificar: python tools/scripts/verify.py

Contratos & OpenAPI 3.1

No SoftForge, o contrato OpenAPI é a fonte única da verdade:

  • Extração Estática a Frio: O comando python tools/scripts/export_openapi.py exporta o openapi.json em menos de 1 segundo sem precisar de servidor rodando.
  • Geração Tipada no Frontend: O Orval lê a especificação e cria tipos TypeScript e hooks TanStack Query com tipagem estrita de ponta a ponta.

FAQ & Solução de Problemas

Como iniciar a documentação com busca offline?

Basta dar duplo clique em docs.bat ou executar .\docs.ps1 na raiz do repositório. O servidor VitePress será aberto em http://localhost:5174.

Posso abrir este arquivo HTML diretamente?

Sim! Este arquivo (manual-offline.html) possui todos os estilos e estruturas embutidos internamente e pode ser aberto com duplo clique diretamente no Windows Explorer sem precisar de nenhum servidor.
