Guia de Início Rápido (Quickstart)

SoftForge — Framework Fullstack AI-Native
100% construído com e para IA • Spec-Driven • Vertical Slice Architecture • Docker-First

1. Pré-requisitos

  • Python 3.12+ (com pip ou uv)
  • Node.js 20+ (com npm ou pnpm)
  • Docker e Docker Compose (opcional para SQLite, obrigatório para Postgres em produção)

2. Inicialização em 3 Passos

Passo 1: Configurar Variáveis

cp .env.example .env

Passo 2: Iniciar o Backend

# Criar ambiente virtual
python -m venv apps/api/.venv

# Ativar e instalar (Windows):
.\apps\api\.venv\Scripts\python.exe -m pip install -e "apps/api[dev]"

# Executar API com recarga automática:
.\apps\api\.venv\Scripts\python.exe -m uvicorn src.main:app --reload

Passo 3: Criar uma Nova Fatia em 2 Minutos

python tools/scripts/slice_scaffold.py --name invoices

Esse comando gera schemas Pydantic v2, models SQLAlchemy 2.0 Async, service, router e testes com SQLite in-memory.

Manual do Framework

1. Por que Vertical Slice Architecture?

Em arquiteturas em camadas convencionais (controllers, services, repositories separados), o código de uma funcionalidade fica espalhado em várias pastas. Quando uma IA atua no projeto, ela precisa manter muitos arquivos na janela de contexto de tokens, gerando alucinações.

No SoftForge, cada fatia é 100% autossuficiente:

apps/api/src/slices/<feature>/
├── schemas.py       # Contratos OpenAPI & DTOs Pydantic v2
├── models.py        # Tabelas SQLAlchemy 2.0 Async
├── service.py       # Lógica pura de negócio
├── router.py        # Endpoints HTTP da fatia
└── tests/           # Testes de integração isolados com SQLite

2. Multi-Tenancy e RBAC

Hierarquia de papéis por Workspace:

  • Owner (Nível 4): Controle total da organização e faturamento.
  • Admin (Nível 3): Gestão de membros e configurações de projetos.
  • Member (Nível 2): Criação e edição de dados do domínio.
  • Viewer (Nível 1): Apenas visualização.

Fluxo de Desenvolvimento com IA

A Constituição do Agente (.ai/AGENTS.md):

O arquivo .ai/AGENTS.md na raiz do projeto instrui qualquer IA (Cursor, Antigravity, Claude Code) a nunca quebrar as regras de fatias verticais, nunca misturar modelos de banco com DTOs e sempre rodar o validador de guardrails.

O Ciclo Determinístico em 7 Etapas:

  1. Scaffold: python tools/scripts/slice_scaffold.py --name <fatia>
  2. Contratos: Definir entrada e saída em schemas.py
  3. Lógica: Implementar service.py e rotas em router.py
  4. Testes: Cobrir com testes assíncronos em tests/
  5. Exportar: python tools/scripts/export_openapi.py
  6. Documentar: Atualizar guias em docs/ e regras em .ai/
  7. Verificar: python tools/scripts/verify.py

Regra de Ouro: Documentação para IA

"Se não está documentado no ecossistema, para a IA não existe."

Agentes de IA constroem e operam sistemas lendo documentação em tempo real. Se você alterar ou adicionar código sem documentar na mesma entrega, os próximos agentes sofrerão alucinações e quebrarão convenções. Toda evolução do código acompanha a evolução da documentação.

Contratos & OpenAPI 3.1

No SoftForge, o contrato OpenAPI é a fonte única da verdade:

  • Extração Estática a Frio: O comando python tools/scripts/export_openapi.py exporta o openapi.json em menos de 1 segundo sem precisar de servidor rodando.
  • Geração Tipada no Frontend: O Orval lê a especificação e cria tipos TypeScript e hooks TanStack Query com tipagem estrita de ponta a ponta.

Fatia: Autenticação Social & OAuth2

A fatia auth oferece suporte nativo a login com um clique via Google e GitHub, além do fluxo tradicional de e-mail e senha:

  • Auto-Linking Inteligente: Vincula contas sociais automaticamente a usuários cadastrados previamente com o mesmo e-mail verificado.
  • Tabela Dedicada: oauth_accounts armazena pares (provider, provider_user_id) únicos por usuário.
  • Senhas Opcionais: Usuários de login social possuem hashed_password nulo com suporte a definição de senha posterior.
  • Desenvolvimento Offline: Mock automático ativado quando nenhuma chave for configurada, permitindo login instantâneo com códigos de teste.
GET /api/v1/auth/oauth/{provider}/authorize  -> Gera URL de consentimento
GET /api/v1/auth/oauth/{provider}/callback   -> Valida code, autentica e emite tokens

Fatia: Billing & Mercado Pago

Motor de faturamento híbrido projetado para o mercado brasileiro e internacional com faturamento B2B (Workspace) e B2C (User):

  • Pix Transparente: Emissão de Pix com chave Copia e Cola e QR Code dinâmico sem redirecionamento externo.
  • Gestão de Planos: Planos Starter (Free), Profissional (Pro) e Empresarial (Enterprise).
  • Controle Declarativo de Quotas: Dependência FastAPI check_quota("projects") que protege a criação de recursos na API.
  • Adaptador Mock Nativo: Testes de checkout e webhooks 100% offline em menos de 2 segundos.
GET  /api/v1/billing/plans         -> Catálogo de planos e limites
GET  /api/v1/billing/subscription  -> Status da assinatura e cotas ativas
POST /api/v1/billing/checkout      -> Emissão de cobrança Pix ou Cartão

FAQ & Solução de Problemas

Por que o arquivo docs/dist/index.html abre quebrado/feio ao dar dois cliques?

O VitePress compila o CSS e os scripts JS com caminhos absolutos como /assets/style.css. No protocolo local file:///, o navegador busca na raiz do disco rígido (onde não existem) e bloqueia módulos ES por políticas de segurança CORS.

Como resolver:

  • VitePress com busca e temas: Dê duplo clique em docs.bat (ou rode .\docs.ps1). Ele abre o site completo em http://localhost:5174.
  • Sem servidor (zero dependências): Abra este arquivo diretamente (docs/manual-offline.html). Ele funciona 100% nativo em file:///!
